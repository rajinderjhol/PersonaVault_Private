# Architecture Decision Records (ADR)

- ADR-001: Environment replaces Context as primary V2 abstraction
- ADR-002: V2 is additive rather than a rewrite
- ADR-003: Strategy and Policy remain separate
- ADR-004: Prediction and Simulation remain separate
- ADR-005: Existing Decision Trace remains canonical
- ADR-006: Existing Memory architecture remains canonical
- ADR-007: Simulation is side-effect isolated
- ADR-008: Learning cannot silently modify Policy
- ADR-009: Model providers remain interchangeable
- ADR-010: Environment is the primary security boundary
