# Whitepapers

Formal documents that define PersonaVault's primitives, guarantees, and
non-guarantees. Each paper makes one narrow claim and defends it.

## Primitive papers
- [Attested Epistemic Transitions](attested_epistemic_transitions.md) —
  how a change to an AI's understanding can be proven to a third party
  without accessing the AI's systems.
- [The Transition Primitive](transition_primitive.md) —
  modeling state change as a first-class architectural event in a governed
  memory system.
- [The Record Primitive](record_primitive.md) —
  persistent representation with differentiated guarantees.
- [The PersonaVault Substrate](substrate.md) —
  the irreducible primitives of governed, evolvable memory.
