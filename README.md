## 🧠 **Core Capabilities**

### 1. **Decision Timeline**
Every decision is captured as a 5-step timeline:
1. 🔍 **Detection** - Event identified
2. 📋 **Policy Match** - Relevant policies applied
3. 🤖 **AI Recommendation** - AI suggests action
4. 👤 **Decision Made** - Human or AI decision
5. 🔒 **Audit Logged** - Full audit record

### 2. **Decision Replay**
Replay any decision at any point in time to see how policies would have changed.

### 3. **Trend Analysis**
Track confidence and decision patterns over time to measure improvement.

### 4. **Explainability**
Every decision is explained with context, reasoning, and confidence scores.

### 5. **Audit Trail**
Complete audit of every decision with full traceability.

### 6. **Behaviour Packs**
Domain-specific intelligence packs that can be installed for any industry.

## 🛠️ **Technical Stack**

- **Backend**: FastAPI (Async Python 3.12)
- **Database**: SQLite (Development), PostgreSQL (Production)
- **Vector Store**: FAISS
- **AI Integration**: Ollama (Local), Gemini (Cloud)
- **Agent Swarm**: 11 specialized agents
- **Memory**: Three-layer (Gas → Liquid → Ice)

## 🚀 **Quick Start**

```bash
# Clone and navigate
git clone https://github.com/yourusername/personavault.git
cd personavault/backend

# Install dependencies
source .venv/bin/activate
pip install -r requirements.txt

# Start the server
./dev_restart.sh

# Access the dashboard
# Open: http://localhost:8000/admin/dashboard
# Login: admin / admin123
```
