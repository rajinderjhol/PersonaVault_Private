# Scripts

Utility scripts for PersonaVault development and operations.

## Top-level
- audit_routes.py   — enumerate and validate API routes
- list_routes.py    — print registered routes
- compile_packs.py  — compile behaviour packs to runtime
- run_pipeline_test.py — run the full decision pipeline end-to-end

## data/
- index_memories_direct.py — rebuild the vector index from storage
- insert_test_memory.py    — seed test memories for development
